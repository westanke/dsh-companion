## 二、发现的问题

### 已修（本轮）

1. **文件列表图标无区分度** —— 全是同一个通用文档图标。改为用 Android 系统已有的
   类型图标（MIME → `resolveActivity` → 应用图标），零维护。
2. **HTML 文件只显示源码** —— `PreviewKind.HTML` 判据对，但消费方只有会话附件面板，
   文件浏览器没有分支。补上分支 + 「源码/结构」切换，默认结构预览。
   回归用例 `HtmlPreviewParityTest` 用源码扫描钉住「两个入口都消费」。

### 已知未修（记录在案）

3. **工具输出横向截断** —— 输出区单行不折行，超出部分被裁掉（每行末尾停在 `/`）。
   应改为横向滚动或折行。截图 48。
4. **复制按钮无反馈** —— `setPrimaryClip` 有调用，但点击后无 toast/提示，用户不知道成没成。
5. **长按选中正文未生效** —— 长按消息正文无高亮、无选择菜单。疑与
   `SelectionContainer` 外层手势冲突（`PITFALLS.md` §SelectionContainer 那一条的邻居）。
6. **轨迹面板「未归属轮次」噪音大** —— 第一屏是 #0~#26 的「其他事件」，
   有效信息要往下翻。历史事件里 turn/step 缺失的那些都被归到这里。
7. **思考条在部分模型下不显示** —— 屏上探针实测 `帧=1106 delta=900 reason=900
   thinkLen=0 liveChat=false`，900 帧 reasoning delta 已抵达但未被接受。
   客户端与插件已双向兜底 `turn/step`（见提交 b831e3a / 1c75aca）；
   **换 deepseek v4.1 模型时思考条正常显示**，故当前所用模型的 reasoning 下发方式
   属内核/模型层差异，用户已确认此项不再追。

## 三、环境事实（下次调试省时间）

- **App 的 `Log.i` 在这台设备上完全不进 logcat**（debug 版也不进）。
  调试只能靠**屏上可见探针**（临时把数值渲染成一行红字）。
- `adb input text` 注入长文本（464 字符 token）会被输入法吞掉大半，长文本请手输。
- 截图估算坐标有 ~190~240px 偏移，**`uiautomator dump` 的 bounds 才是权威**。
- 设备上的 debug 包用 `apksigner` 以**发布钥匙**重签即可覆盖安装 release 版。
- `dsh --host 0.0.0.0` 会被拒（安全），远程访问用 `POST /manage/remote/enable` 开启。
